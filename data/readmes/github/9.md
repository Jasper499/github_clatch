# There is no official XScreenSaver GitHub repository.
I am [jwz](https://www.jwz.org/), the author of [XScreenSaver](https://www.jwz.org/xscreensaver/), and I do not publish a public source code repository. I publish releases as tar files on the [official web site](https://www.jwz.org/xscreensaver/) and only there. If you see any other XScreenSaver repository (on GitHub or elsewhere) that has nothing to do with me and you should not trust it.

I welcome submissions and change requests via [email](mailto:jwz@jwz.org?subject=XScreenSaver%20has%20no%20git%20repo). It's fine. You'll get over it.
